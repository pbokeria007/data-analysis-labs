# Трансформация данных: квантование, фильтрация, сглаживание

Практическая работа N26  
Тема: Разбиение данных, квантование и фильтрация.

---

## Данные

- 360 значений температуры за 2023 год (12 месяцев по 30 дней)
- Диапазон: от -9.9°C до +34.7°C
- Средняя за год: +8.4°C

---

## Выполненные действия

### 1. Разбиение по месяцам
Для каждого месяца вычислены: средняя, минимум, максимум, стандартное отклонение.

### 2. Квантование
Непрерывные значения преобразованы в 4 категории:
- Холодно: t < 0°C
- Прохладно: 0°C <= t < 10°C
- Тепло: 10°C <= t < 20°C
- Жарко: t >= 20°C

### 3. Фильтрация выбросов
Выброс: отклонение более чем на 15°C от среднемесячной температуры.

### 4. Сглаживание
Применено скользящее среднее с окном 7 дней для выявления долгосрочного тренда.

---

## Результаты

- Максимальная средняя температура: июль, +21.9°C
- Минимальная средняя температура: январь, -5.5°C
- Выбросов обнаружено: 0
- Квантование: наибольшая доля дней приходится на категорию "Тепло" (33.9%)
