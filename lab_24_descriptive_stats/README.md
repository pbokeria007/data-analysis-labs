# Описательная статистика

Практическая работа N24  
Тема: Описательная статистика в MS Excel.

---

## Данные

- Выборка: n = 100 случайных чисел.
- Диапазон: от 0 до 100 (два знака после запятой).
- Генерация: СЛУЧМЕЖДУ(0;10000)/100

---

## Выполненные действия

С помощью инструмента "Описательная статистика" пакета анализа Excel рассчитаны:
- среднее арифметическое
- медиана
- мода
- стандартное отклонение
- эксцесс
- асимметричность
- размах (интервал)

---

## Результаты

| Показатель | Значение |
|------------|----------|
| Среднее | 54.04 |
| Медиана | 53.82 |
| Стандартное отклонение | 29.15 |
| Асимметричность | -0.09 |
| Эксцесс | -1.30 |
| Размах | 99.48 |
| Мода | отсутствует (все числа уникальны) |

---

## Инструменты

- Microsoft Excel (Пакет анализа - VBA)

---

## Вывод

- Среднее и медиана близки: распределение относительно симметрично.
- Эксцесс отрицательный: распределение более плоское по сравнению с нормальным.
- Размах составляет 99.5, значения покрывают практически весь диапазон от 0 до 100.

Освоен инструмент "Описательная статистика" для быстрой характеристики выборки.
