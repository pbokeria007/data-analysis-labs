# Регрессионный анализ

Практическая работа N25  
Тема: Создание регрессионных математических моделей в MS Excel.

---

## Данные

- Сгенерированные данные (X и Y)
- Цель: выявить математическую зависимость между переменными

---

## Выполненные действия

Построены три типа регрессионных моделей:

1. Линейная регрессия
2. Экспоненциальная регрессия
3. Логарифмическая регрессия

Для каждой модели построена точечная диаграмма, добавлена линия тренда, отображены уравнение регрессии и коэффициент детерминации (R2).

---

|---------------|-----------|-----|

| Логарифмическая | y = ... | ... |

---

## Инструменты

- Microsoft Excel (линии тренда, регрессия)

---

## Вывод

Наилучшую аппроксимацию обеспечивает [название модели] (согласно значению R2). Полученные уравнения могут использоваться для прогнозирования.
