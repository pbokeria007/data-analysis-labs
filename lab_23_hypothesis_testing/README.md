# Проверка статистических гипотез

Практическая работа N23  
Тема: Проверка статистических гипотез для двух и более выборок.


## Данные

- Две случайные выборки (A и B), n = 10 каждая.
- Диапазон значений: 74-78
- Уровень значимости: alpha = 0.05

## Выполненные действия

### 1. Парный двухвыборочный t-тест
- Нулевая гипотеза (H0): средние значения выборок равны.
- Альтернативная гипотеза (H1): средние значения различаются.
- Тип теста: парный (тип 1).
- Полученное p-value: 0.0836.

### 2. Двухвыборочный t-тест с одинаковыми дисперсиями
- Диапазон данных: 0-10, n = 10.
- Тип теста: двухвыборочный с равными дисперсиями (тип 2).
- Полученное p-value: 0.1489.


## Результаты

| Тест | p-value | Решение |
|------|---------|---------|
| Парный t-тест | 0.0836 | p > 0.05, H0 не отвергается |
| Двухвыборочный t-тест | 0.1489 | p > 0.05, H0 не отвергается |

Вывод: статистически значимых различий между выборками не обнаружено.


## Инструменты

- Microsoft Excel (функция СТЬЮДЕНТ.ТЕСТ)
- Генерация случайных данных: СЛУЧМЕЖДУ()

## Вывод

Оба теста показали отсутствие статистически значимых различий между выборками. Полученные навыки применимы для A/B-тестирования и проверки гипотез в бизнес-задачах.
