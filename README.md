# data-analysis-labs

# Портфолио учебных проектов по анализу данных

В этом репозитории собраны мои работы в рамках курса "Информатика" (РТУ МИРЭА, 2025–2026).  
Проекты охватывают ключевые этапы работы с данными: от первичного анализа до построения регрессионных моделей.

##  Содержание

lab_20_eda | Разведочный анализ данных (EDA) Excel, гистограммы, boxplot 
lab_23_hypothesis_testing | Проверка статистических гипотез (t-test) | Excel, СТЬЮДЕНТ.ТЕСТ |
lab_24_descriptive_stats | Описательная статистика | Excel, Пакет анализа |
lab_25_regression | Регрессионный анализ (линейная, экспоненциальная, логарифмическая) | Excel, линии тренда |
lab_26_data_transformation | Квантование, фильтрация, сглаживание временных рядов | Python (Pandas, Matplotlib), Google Colab |

Навыки, которые демонстрируют эти работы:
- Работа с данными в Excel и Python
- Построение и интерпретация графиков
- Проверка гипотез
- Регрессионный анализ
- Обработка временных рядов
