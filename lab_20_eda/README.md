# Разведочный анализ данных (EDA)

**Практическая работа №20**  
**Тема:** Первичный и разведочный анализ данных.

## Данные

- Файл: `sales_4.csv`
- Количество наблюдений: **201**
- Показатели: **цена продажи** и **объём продажи**
- Тип данных: количественный непрерывный
- Пропусков: **нет**

##  Что сделано

1. **Гистограммы распределения** — для цен и объёмов продаж.
2. **Точечная диаграмма (scatter plot)** — визуализация связи между ценой и объёмом.
3. **Ящики с усами (boxplot)** — для выявления выбросов и квартилей.

##  Результаты

### Цены продаж
- Основной диапазон: **20–50**
- Пик: **30–40**
- Медиана: **≈38**
- Обнаружено выбросов: **6**

### Объёмы продаж
- Основной диапазон: **40–100**
- Пик: **60–80**
- Медиана: **≈75**
- Обнаружено выбросов: **4**

### Связь между ценой и объёмом
- Наблюдается **отрицательная корреляция**: при увеличении цены объём продаж снижается.
- Визуально выделяются **5–7 потенциальных выбросов**.
